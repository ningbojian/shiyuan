项目资料

氏源是一个数据库课程团队项目：以姓氏为核心，组织姓氏起源、文化、人口分布、历代名人和迁徙路径，并通过地图、词云、关系图和时间轴做可视化。

本仓库是课程结束后的整理版：保留完整 Django 后端、模板、静态资源和演示数据，并修复了原项目中的硬编码密钥、明文密码比较和外部图片依赖。完整原始数据（300+ 姓氏）没有提交，仓库里只放李、王、张、丁四个示例姓氏。

技术栈

Django 5.2 SQLite / MySQL ECharts pyecharts HTML / CSS / Vue Python 3

数据模型

表作用
surname姓氏基本信息、起源、文化、迁徙、人口分布文本
province省份维度
dynasty朝代及起止时间
distribution姓氏 × 省份的人口比例
famous姓氏 × 朝代的历史名人
user / comment用户注册登录与评论

主要功能

  • 用户注册、登录、个人中心
  • 按姓氏搜索与热门姓氏推荐
  • 人口分布地图、历代名人朝代树、词云、姓氏关系图、迁徙路径
  • 评论增删改查（课程原型；接口使用 GET，生产环境应改为 POST + CSRF）
