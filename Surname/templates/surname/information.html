项目资料

氏源是一个数据库课程团队项目：以姓氏为核心，组织姓氏起源、文化、人口分布、历代名人和迁徙路径，并通过地图、词云、关系图和时间轴做可视化。

本仓库是课程结束后的整理版：保留 Django 后端、模板、本地静态资源和演示数据，并修复了原项目中的硬编码密钥、明文密码比较、越权接口与外部脚本依赖。课程源目录（346 个文件夹）不随仓库提交；当前目录收录 348 个姓氏，其中 33 个为整理条目，315 个为课程原始资料（未校订）。李、王、张、丁四姓保留课程原始文本，并合并了原始人物资料。

技术栈

Django 5.2 SQLite 本地 ECharts HTML / CSS Python 3

数据模型

表作用
surname姓氏基本信息、起源、文化、迁徙、人口分布文本
province省份维度与地图中心点
dynasty朝代及起止时间
distribution姓氏 × 省份的示意强度（0–100，非占比）
famous姓氏 × 朝代的历史人物
clan / surname_relation宗族与姓氏源流关系
migration_event按朝代排序的迁徙事件
auth_user / profile / comment账号、资料与评论
favorite / reading_history收藏与浏览历史

主要功能

  • 用户注册、登录、个人中心、密码与资料修改
  • 按姓氏、拼音、首字母搜索，热门姓氏推荐
  • 人口分布地图、历史人物、词云、姓氏关系图、迁徙时间轴
  • 收藏与浏览历史（仅本人可见）
  • 评论仅允许登录用户通过 POST + CSRF 提交，删除与隐藏均校验权限

数据来源与再生成

姓氏文本依据课程资料与通行姓氏源流概述整理；演示条目由脚本生成并逐条标注来源说明，不复制参考网站的受版权保护内容。

唯一可复现数据源为仓库内 data/catalog.json。重新生成与校验命令见项目文档 docs/DATA.md。
