从姓氏出发，看见中国文化的迁徙

氏源是一个课程团队项目：以姓氏为核心，组织姓氏起源、文化、人口分布、历代名人和迁徙路径，并通过地图、词云、关系图和时间轴把数据可视化。

技术栈：Django + SQLite/MySQL + ECharts/pyecharts；支持用户注册登录、姓氏检索和评论互动。
